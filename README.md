# NoDramaBot 🔥

AI-помощник для трафик-менеджеров и менеджеров по размещению hh, который помогает отвечать на сложные вопросы клиентов без конфликтов.

## Функционал
- GPT + база кейсов (RAG)
- Чат режим (GPT-4o)
- Демо режим "разыграть конфликт"
- Админка для пополнения базы
- Семантический поиск

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
